# 轨迹系列全要素攻略与矢量 PDF 出版级生成系统

> 针对 Falcom《英雄传说：轨迹系列》打造的高清战术终端风格排版与出版级矢量 A4 PDF 自动化流水线。  
> **完整收录 12 部作品**：空之轨迹 the 1st 重制版、the 2nd 重制版、零之轨迹、碧之轨迹、闪之轨迹 1-4、创之轨迹、黎之轨迹 1-2、界之轨迹。

---

## 📖 方案概览

本项目提供了一套完全工程化、解耦、自动化的 JRPG 攻略数据抓取、语义解析、排版构建与无损矢量 PDF 导出系统。

版面视觉设计严格参照《轨迹系列》经典的 **游击士协会战术导力终端（Tactical Orbment Terminal）** 交互风格，引入深海蓝/帝国绯红/夜行冷靛等 Saga 专属主题配色、金色高光、导力回路同心圆几何纹样，并针对专业打印规范进行了深度 CSS Paged Media 优化（包含 `@page` 边距控制、`break-inside: avoid` 防孤行折断、清晰数据表格与时限预警角标），专为平板大屏翻阅或高精度双面实体打印设计。

## 🏗 系统架构与管道

全管道由高内聚的模块构成：

```
[trails-game.com / 官方攻略数据库]
                 │
                 ▼
          src/scraper.py           (网页数据持久化抓取与缓存引擎)
                 │
                 ▼
          src/parser.py            (首作空轨 1st 深度解析器)
       src/universal_builder.py    (全 12 作通用数据提取与 A4 Paged Media 排版)
                 │
                 ▼
        templates/style.css        (游击士终端 JRPG 主题打印样式表)
                 │
                 ▼
        src/pdf_exporter.py        (Chrome Headless Skia 矢量导出驱动)
                 │
                 ▼
        src/batch_runner.py        (全 12 作自动化批量并发构建引擎)
              main.py              (统一 CLI 命令交互入口)
                 │
                 ▼
               dist/*.pdf          (全 12 部作品高清独立 PDF)
```

## 🚀 快速上手与操作指引

### 1. 环境准备
- **Python**：3.10 或更高版本
- **浏览器**：Google Chrome 或 Chromium（支持标准安装路径，或通过环境变量 `CHROME_BIN` 自定义指定）
- **操作系统**：macOS / Linux / Windows

### 2. 命令行一键执行

```bash
# 批量编译并生成全部 12 部作品的独立 PDF
python3 main.py --all

# 指定仅生成某一部作品 (以《界之轨迹》为例)
python3 main.py --game kai

# 默认生成标杆作品《空之轨迹 the 1st 重制版》
python3 main.py

# 仅生成 HTML 排版文件进行浏览器快速调优与预览 (不调用 Chrome)
python3 main.py --game zero --html-only
```

## 🧪 自动化测试验证

运行全量单元测试与端到端管道测试：

```bash
python3 -m unittest discover -s tests
```

测试集涵盖：
- `test_parser.py`：数据模式验证、任务全要素、BP 累计值及字段容错。
- `test_builder.py`：HTML 生成逻辑、CSS 注入、表格防截断与章节锚点。
- `test_pdf_exporter.py`：Chrome 探测、临时隔离导出及异常路径拦截。
- `test_main.py`：CLI 入口参数解析、`--all`、`--game`、`--html-only` 开关。
- `test_pipeline.py`：端到端全管道数据流转自动化测试。
